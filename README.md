## Что делает программа
Программа выполняет поэтапную очистку «грязного» набора данных перед обучением ИИ-моделей:
- удаляет строки с пропусками в критичных столбцах (`name`, `age`);
- заполняет пропуски в столбце зарплаты (`salary`) средним значением;
- удаляет полные дубликаты записей (`drop_duplicates`);
- находит аномальные выбросы возраста (> 100 лет) и заменяет их медианой по нормальным значениям;
- приводит строковый столбец стажа (`experience`) к целочисленному типу (`int`) и сохраняет результат в `clean_data.csv`.

## Как запустить
1. Установите зависимости: `pip3 install -r requirements.txt`
2. Запустите скрипт: `python3 main.py`
